# SMJ App (React + Vite)

## Ejecutar en local (modo desarrollo)

```bash
npm install
npm run dev
```

Abre la URL que muestra Vite (normalmente `http://localhost:5173`).

## Previsualizar como GitHub Pages (producción)

```bash
npm run build
npm run preview
```

`preview` sirve el build final y es la forma más cercana a cómo se verá publicado en GitHub Pages.

## Publicar en GitHub Pages

```bash
npm run deploy
```

Este comando construye el proyecto y publica la carpeta `dist` en la rama `gh-pages`.

URL esperada de publicación:

`https://aescuderof.github.io/SMJ/`
